# EMS S2 未实现策略类型标注/禁用 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让「生成计划」对未支持的策略类型（DEMAND / DR / SOC_CTRL / TIME）不可用但可解释，并为 0 点历史计划在计划页提供空态兜底。

**Architecture:** 纯前端迭代。新增 `dicts.ts` 纯函数谓词 `isStrategyGeneratable`（硬编码支持集合，注释对齐后端 `PlanGenerator.java`）；`EmsStrategy.vue` 据此禁用生成按钮 + tooltip + 下拉标注 + 保存软警告；`EmsPlan.vue` 对 0 点计划渲染 `el-empty` 空态，配套修复 `useEChart` 容器消失不清理实例的缺陷（否则 v-if 切换后图表无法重新初始化）。

**Tech Stack:** Vue 3.5 + Element Plus 2.9（全局注册）+ ECharts 5.6（useEChart 封装）+ Vitest 2 + vue-tsc 2。

**Spec:** `docs/superpowers/specs/2026-08-08-ems-s2-design.md`

## Global Constraints

1. **纯前端，不触碰后端 API 契约**。无任何新接口、新依赖。
2. **可生成集合唯一来源**：`STRATEGY_GENERATABLE_TYPES = ['PEAK_VALLEY']`（`frontend/src/utils/dicts.ts`），注释必须指向 `PlanGenerator.java`。其余 4 类型 DEMAND / DR / SOC_CTRL / TIME 一律判定不可生成。

```ts
function initIfNeeded(el: HTMLElement | undefined): void {
  if (!el) {
    // 容器被 v-if 移除：释放实例与观察器，避免重新挂载时被残留 chart.value 挡住
    observer?.disconnect()
    observer = null
    chart.value?.dispose()
    chart.value = null
    return
  }
  if (chart.value) return
  chart.value = echarts.init(el)
  if (pending) {
    chart.value.setOption(pending, { notMerge: true })
    pending = null
  }
  observer = new ResizeObserver(() => chart.value?.resize())
  observer.observe(el)
}
```
